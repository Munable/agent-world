额度与会话选项

委托或接续时可选。整理计入这个目标的模型请求总额度，至少剩 2 次请求才能整理后继续；每个目标最多整理一次，不自动重试。

点击委托才授权行动。Agent 可在额度内分段继续同一目标；一段请求结束不代表目标完成。收回或亲手行动会接回控制，已完成的动作保留。

接续额度与请求详情

默认授权 16 次请求，单目标最多 32 次；在额度内自动接续。额外授权不重置原目标和已确认动作。

只保存在本机，不作为公开事实。保存不调用模型，也不授权行动。

模型与连接

模型列表来自本机宿主实际可用的已有服务，额度与费用取决于所选服务；沿用原有服务凭据与隐私设置。

明确委托按目标的动作与请求总额度执行，每段建议 8 个推理步骤，每个请求最多 16 次世界读取或行动；没有已授权目标时，现场变化不会自动启动模型。
