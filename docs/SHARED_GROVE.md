## 材料、能力、关系与后果合同

- 对象保持稳定 ID、版本和生命周期；材料批次为 `matter`，分别位于 `body / contained / surface / absorbed`，整数逻辑单位 `u`，每份原料的转换由注册定义提供。批次中的来源只作归因，不产生产权。
- 本体与内容分别燃烧。材料定义决定可燃性，生成者删标签不能得到不燃木；开放石容器内的燃料可以燃烧而石本体保留。闭合关系控制内容暴露，表面和吸附水分别记录，不使用“油碗／油布”配对分支，不承诺真实化学。
- 水从实际来源转移，吸水实际增载；水量、燃料、湿度是批次派生投影，不能作为第二份可写权威状态。雨／资源生长是明确 source，蒸发／燃烧是明确 sink。按材料：期末量＝期初量＋source－sink。
- 物理父关系唯一，容纳／绑定形成有界无环森林；子对象不因装卸、漂流或破损复制。位置和索引从关系派生；授权与当前地面／背包／安全区合同一致。
- 材料和注册构造决定容量、承载与浮力，模型只选择组合，不提交任意数值能力。局部载荷包括全部物质，子树总载荷只计一次；吸水或装载可使过载，完整度降低承载，结构失效释放原对象与真实储水，改变漂流资格。
- 人的转移立即改变数量与合法性；损伤、燃烧、干燥每物理 tick 各推进一次。多点击不加速速率过程。破损只转换一次，释放和事件与状态原子提交；拆卸只退还仍存在的投入材料。

## 规则执行与容量

可信 Python 注册声明阶段、依赖、读写／合并和受限效果；不允许运行模型脚本。执行为阶段快照、数量与目的容量分配、效果合并和一次提交。依赖循环与独占字段冲突在注册时拒绝，状态不得最后写覆盖或截断丢量。

阶段固定：环境供水／接触／干燥 → 燃烧消耗与载荷损伤 → 破损释放 → 泄水接触／熄火与资格重算 → 漂流。每目标速率推进一次；新点燃批次下 tick 才消耗。释放产生的新载荷立即影响资格，新增速率损伤下 tick 才推进；泄水不撤销本 tick 已烧掉的物质。反馈留在下一 tick 过程状态，不递归求无限固定点。

过程保存参与对象、状态、规则版本及逻辑步位置。普通操作和 tick 复用 Runtime 原事务／Receipt。失败全回滚，未知写结果查同一 Operation 的 Receipt 或原请求重放；停机暂停物理时间，恢复不补离线结算，不依赖模型记忆重建事实。
