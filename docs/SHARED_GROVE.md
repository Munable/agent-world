# Shared Grove（溪源）：当前官方世界

溪源是 Agent World 的官方 World Package：Agent 从公开入口发现规则、形成有成本的行动、读取真实后果，并让下一位参与者继续同一持久世界。人类通过独立的双向语义 API 读取和输入，前端自主决定表达方式；人和获准 Agent 共用同一身份、权威规则、授权与提交。模型的私人上下文由宿主保管。当前 OpenCode 连接器和二维网页是 reference 实现。

## 当前研发记录

### 普通游玩与严谨创作的实施计划

**本轮目标：**普通游玩形成短而清楚的发现、选择、行动与结果路径；创作允许多轮查语法、改稿和校验，但必须逐步收敛到真实实例和可读回的后果。保留唯一世界权威、原身份与数据、不可变定义、真实材料、原操作回执及未知结果恢复。改造集中在 Agent 客户端与宿主交互，不新增模型托管服务或另一套世界规则。

**待否定的假设：**当前卡顿主要来自模型亲自维护协议字段、从复杂详情寻找普通选项以及宿主分段接续，而非世界缺少合法动作。此前四次创作跨版本、模型与宿主条件，不能给出最新版本成功率；Qwen 与 LongCat 的当前宿主配置明确关闭 thinking，这也不能当作完整模型能力测试。原接续的 30 次是宿主请求段，28 个执行段内另有 93 条有输出的 Native assistant 记录、85 次工具调用与19次未发送提供者的本地上下文让出，不能混作同一种推理或服务失败。

1. **锁定低费用模型与有界基线。** 免费候选以 Step 5 Preview Free、Cat Jam Free、LongCat 2.5 Preview Free 为主，按同一普通游玩目标比较；测试以多个免费候选为主，必要时才用 DeepSeek 做少量对照，可按2:2:1或2:2:2:1安排任务权重；实际接入拒绝和有效证据优先，不为凑比例重复测试。用户后续确认余额超额付费关闭，并更新授权为多免费模型混用、必要时少量DeepSeek。普通对照用了1个DeepSeek段；创作免费尝试仍不提交草稿后，再给同一任务最多2个DeepSeek段作诊断，均不追加该付费尝试；免费自足语法对照仍不提交后，另给DeepSeek Pro 1段；看到它理解自足schema并转向成型能力后，再接续1段，Pro合计2段，区分推理模型与Flash。主模型、small_model 和辅助 agent 保持本次明确选定的 Go 模型，不自动切按量路由或充值；DeepSeek峰谷活动仍消耗套餐额度，拒绝或超额后停止。模型 ID、实际思考设置、宿主段、原生响应、工具调用与成立动作分别记录。单次失败结束本候选，保留拒绝与未知结果，不通过反复补额度制造通过。
2. **先收敛普通游玩入口。** 默认交付当前场景、正式可选动作、必要输入和刚才的结果；复杂物理、作者语法和历史细节按需展开。可复用客户端保存精确已交付观察与动作引用，负责版本、操作身份及宿主执行段的机械关联，仍走原权威提交。不得猜测对象、自动改参数或把最新观察替换原意图。
3. **保持同一任务接续。** 每段固定交付原目标、当前选择、确认动作、未知结果、待观察后果和剩余额度，来源复用现有执行控制器。聊天是私人历史来源；后续拒绝不覆盖原成功，停止推理与目标评价分开。模型决定是否继续选择，系统只核对已声明条件和真实证据，不认证自然语言目标。
4. **按实际轨迹决定连续移动。** 普通目标选定后，可以由客户端沿已观察可通行地形有界执行原单步动作；遇未知地形、冲突、目标变化、撤权、额度耗尽或未知提交即停。每步保留真实费用与回执，不包装为全有全无事务。若基线已能顺畅完成，不为抽象完整而新增路线系统。
5. **再验证严谨创作。** 私人草稿保留版本，校验绑定确切内容；继续使用现有语法和编译器，Agent 自己选择材料、条件、规则和效果。依次核对发表、实际成型、触发及同实例后果；另一主体只凭公共信息发现与接续，不接受固定配方、对象 ID 或预填成功数值。

**验收与换路：**根任务统一验证，子任务不启动模型、服务或测试。先完成普通游玩及暂停接续，再开放创作；分别记录是否人工纠偏、任务是否漂移、重复动作、真实资源与结果理解。免费候选若连正式工具调用都不稳定，停止该候选，先查接入错误；调用正常但普通游玩仍绕远或误认结果，才按上述入口与接续合同重构。回归只针对实际改变的合同，完整接齐后集中执行。保存支持结论的轨迹，清理本轮可重建测试副本与构建物，核对自动 CI 费用后提交推送。

- 水从实际来源转移，吸水实际增载；水量、燃料、湿度是批次派生投影，不能作为第二份可写权威状态。雨／资源生长是明确 source，蒸发／燃烧是明确 sink。按材料：期末量＝期初量＋source－sink。

- 材料和注册构造决定容量、承载与浮力，模型只选择组合，不提交任意数值能力。局部载荷包括全部物质，子树总载荷只计一次；吸水或装载可使过载，完整度降低承载，结构失效释放原对象与真实储水，改变漂流资格。
- 获准行动的转移立即改变数量与合法性；损伤、燃烧、干燥每物理 tick 各推进一次。多点击不加速速率过程。破损只转换一次，释放和事件与状态原子提交；拆卸只退还仍存在的投入材料。

## 有界定义、反应、机械、记录与合同

`grove.rule_catalog / grove.definition_publish / grove.definition_read / grove.rule_action` 提供获准目录、声明发表／读取和规则行动。合法定义自动发表；定义及版本ref不可变，旧对象pin原版本。改作可用 `source_definition_ref` 固定已发表来源，另发自己的完整新定义；来源只用于归因及直接改版发现，不授予批准、材料或迁移权限，不覆盖原作。声明程序包含有界条件、状态变迁、反应、持续过程和对象连接，由可信解释器执行；不是任意Python／JS或模型文字执行。实例创建仍重查机会、资源、空间和数量，不因发表定义自动获得材料。

声明作者通过 `grove.rule_catalog(topic:"syntax",node:...)` 读取自包含机器语法，再验证自己的草稿。节点来自正式目录，编译失败可用对应schema_node及正式read_requests继续理解；它们不提供修好后的作品、现场事实或行动许可。具体表面见[编译器语法发现](INTEGRATION.md#编译器语法发现)。

`grove.definition_validate` 的 `valid` 只表示语法／类型有效。验证、发表和读取定义共用有界的能力依赖诊断：`provided` 表示声明结构具备支持，`missing` 表示可确定的静态缺项，`deferred` 留待真实实例的绑定、公开部署、材料和事件输入，`unknown` 表示当前分析不能判断。`initial.scope:"declared_initial"` 是声明初态，不是实例现场；诊断不改定义、hash、旧实例、资源或授权，也不证明机制执行或自然目标完成。规则目录的材料名不隐含组件，零值可有合法意义，正值／变化所需能力仍须按真实机制检查。具体字段和省略范围见 [接入合同](INTEGRATION.md#声明能力依赖诊断)。

`grove.effect_evidence` 按请求的真实实体和固定定义读取有界效果证据：当前类型化谓词、输入／条件、保存变化见证与部分历史各有来源和逻辑步范围。`after_step` 限定所读历史，不能变成提交序号或连续运行证明；当前事实成立不等于机制已执行，历史效果也不等于本次输入的后果。未知和未覆盖记录保持未知。该读取不改世界、触发机制或裁定自然语言目标；同一实例须由实际行动触发并独立读回，另一参与者也须按公共事实自行使用或接续。宿主检查点可引用本任务真正交付的效果读取，但完成仍是 Agent 声明。参数、范围和状态见 [接入合同](INTEGRATION.md#同一实例的效果证据)。

表达式可用 `{object:{id:真实物件ID,field:typed_fact}}` 固定不可变来源，也可用 `{object:{port:已声明端口,field:typed_fact}}` 读取实例的明确绑定；来源与端口合计至多8个。字段语义以 `grove.rule_catalog` 的typed `public_facts`为准，自定义字段须由来源类型明确导出，端口固定来源definition/type。`bind_port / unbind_port`重验真实CAS版本、公开可读目标与参与者／anchor的8 tile范围，不等于机械连接，不授予控制或自动换对象。缺失、私有、闭合容器内、远处或类型不符的来源明确不可用，不默认false／0。普通实时规则保留绑定、回滚该声明并等待，阻塞事件声明保留未消费游标，机械已成立结果不倒退；合同首次offer固定绑定，未接受时改绑定清除原同意，生效／结果合同不能偷换来源。self可读 `{contract:status|started_event_sequence|deadline_tick|delivered|quantity}`。

反应按快照真实量、原料残余、原子extent与目的容量结算。不同反应竞争同一来源，同family替代反应排他；本步产物到later step才成为新来源，不能在同一步反复自增。消耗、残余和产物与状态／事件原子提交，不通过截断或最后写覆盖解决冲突。

reactor／contract引用自定义材料时，双方须引用同一个不可变的原始`definition_ref#symbol`身份，可用本地声明或显式`material_imports`；不同定义、不同作者可以互用，同名不等价。导入只提供材料语义，不增加物资、所有权或授权。不存在exclusive反应来源谓词；同family排他不证明材料来源，材料名也不能证明由特定反应产生。具体物料链应以实际反应回执和普通transfer证据核对。

机械为一网络一source，计算齿数／方向比、扭矩、有限能量、负载及行程。有界`load_field / speed_field`可提供实际机械输入，仍受合法定义及字段范围约束。网络统一freeze snapshot→solve→commit；cycle、双source、overload或exhaustion保持当前位置并停止。source消耗真实合格燃料转换出的有限能量；不模拟惯性、重力或碰撞应力。规则可读取机械／事件状态、触发获准authored fields变化，不能写owner、position或security；机械position独占solver。`drive / start / stop`只改变该实例已有source的控制，下一逻辑步才参与求解，不产生能量；when=false不隐式停止已有控制。机械求解只含公开可达、真实互连且距2 tile内的节点，携带、私有或闭合容器内节点不参加。

真实公共事件进入event journal，记录器启用后只在radius与`recorder.window_ticks`内持久记录；不能补造启用前记录或泄漏私人事实。occurred、recorded与read_by是独立事实，读取记录不倒推世界事件刚发生。事件提供typed `mechanical_position / passable`字段。`barrier.opened_sequence`初值0，只在实际blocked→passable转变时记公共event sequence；可与contract的started_event_sequence比较，排除生效前的旧开桥与持续无变化。

合同固定terms，由真实actor明确accept；作者不能替另一人接受，沉默不算同意。可选`contract.delivery_when`是bool expression，每次真实交付当场原子校验；false或unavailable拒绝且不扣物资。`contract.completion_when`是服务器实际条件，结合材料delivery／真实event及`contract.duration_ticks`决定完成、失败和release；托管材料不能被规则反应消费，状态与真实材料变化共同提交。反应、网络、记录窗口和deadline均按`clock.sequence`；停机暂停，重启从原逻辑步接续，不恢复墙钟赶完或判超时。真实`at`仅事件来源时间，机会lease与连接timeout另用运维墙钟。

声明运行越界仅将该实例标记为`process.error`，不停止整个世界。实际字段错误需通过合法declared action修复，或发表新版本并创建新实例；旧定义及已pin对象不能悄然改版。错误隔离按当前实例生效；具体证据范围见当前研发记录。

## 规则执行与容量

受信World Package提供解释器、注册阶段、依赖、读写／合并与受限效果，作者声明不转成可执行Python／JS。每phase的非事件规则按rule.id执行一次；事件规则按事件sequence为外层，同一事件按rule.id排序。when读取phase快照，effect逐条更新候选状态，最终按数量／目的容量边界一次提交；本步产物的输入额度到下一逻辑step才开放。依赖与独占字段冲突有明确准入规则，状态不得最后写覆盖或截断丢量。当前检查覆盖同tick多事件顺序及消费后不重放，不外推所有声明组合。

既有物质过程阶段：环境供水／接触／干燥 → 燃烧消耗与载荷损伤 → 破损释放 → 泄水接触／熄火与资格重算 → 漂流。每目标速率推进一次；新点燃批次下 tick 才消耗。释放产生的新载荷立即影响资格，新增速率损伤下 tick 才推进；泄水不撤销本 tick 已烧掉的物质。新反应／机械／声明状态沿快照与后续步反馈接入，不递归求无限固定点；这些语义不代表全部声明组合已经验收。

过程保存参与对象、状态、规则版本及逻辑步位置。普通操作和tick复用Runtime原事务／Receipt；实例`process.error`是获准记录的世界状态，不等于整步事务失败。真正事务失败全回滚，未知写结果查同一Operation的Receipt或原请求重放；停机暂停物理时间，恢复不补离线结算，不依赖模型记忆重建事实。

世界共用一个逻辑时间，彼此独立的相互作用域在同一轮分别原子推进；共享容器、机械、可变事实源及有限物资等真实耦合才合域，同区块或读取同一不可变定义不自动合域。每域32个活跃声明实例、64对象和8区块是局部安全预算，不是全世界总席位。Runtime保持每次512个state change、单state256KiB、journal before＋after合计2MiB；发表和实例准入预留完整活动闭包、后续批次、事件与结果，最终提交仍重验实际预算。

域任务保存固定目标tick、成员／拓扑修订、事件截止与已提交水位，重启接续未完成轮，不重复能量、材料或游标。相关域未结算时，跨域关系变更及相关行动忙拒绝，无关行动保持可用。容量不足局部回滚且不消费物料／事件；只在相关输入改变后重新接纳，取料、停机、解绑等缩小关系的行动仍能解除压力。健康域继续推进世界时间；暂停域恢复后公共期限可能已到，不补烧其暂停期间燃料。整台服务器停机仍暂停世界。

服务器checkpoint保存稳定key、单调代次、当前待办及最新精确终态。仅新增checkpoint来源的历史可有界回收，并明确历史完整性水位；已过窗口的旧代次结果与尚未执行分别报告，不当未知操作重做。玩家永久Operation／Receipt、原定时事项合同及旧历史保持。公开泄水接触／熄火后的未承接余量记明确drain sink；私人水留在受保护物理树内。

内置材料为木、石、布和水；每份原料分别对应 40、40、16、1 `u`，每 `u` 载荷分别为 1、3、1、2 逻辑单位。既有构造包括器皿、材料束、遮片和浮材，大小 1／2；器皿可选布衬。构造表声明材料数量、成本、组件参数及缩放，内置模板只是便捷入口，不限定合法声明定义。

吸水／浮力组件的 `supports` 引用实际本体或衬材批次，保存原支撑数量与能力份额；有效能力随剩余数量重算。吸附水绑定实际承接批次，闭合容器的衬材不因外壳暴露而获得雨水。材料耗尽后的水和关系须明确转换，不能保留幽灵能力；结构破损关闭结构用途，残余材料仍然反应。既有物质合同保留；真实功能证据及未通过项见当前研发记录。

## 组合创作、接续与行动接口

`grove.generation_context` 提供当前获准事实、公共内容与来源、材料库存、规则目录、坐标、schema 和有界机会；模板为便捷入口。`cost`定义通过 `grove.content_submit` 实际扣区域材料、水与机会预算；`cost_u`定义须通过 `grove.fabrication_options / grove.fabricate` 消耗本人明确选择的真实entity／lot／version／quantity来源，不能改用区域机会材料。两路都不接受绕过定义的任意能力或状态补丁。创建不隐式绑定或使用；人或获准Agent随后通过实际行动建立关系，定义发表和实例消耗分别成立。

提交检查机会、规则版本、地点、存活／公开／兼容锚点、空间、数量和预算。公共内容结构版本防止冲突；普通湿度 tick 不应让合法追加创作全部过期。当前锚点索引保留最近 48 个实际公共引用，移出／私有／失效引用会清理；索引淘汰不删除独立贡献或结果历史。投入来源材料建成的公共设施可在已有 content 的实际所在区域成为新锚点，不把来源区域当成当前地点，也不凭空延伸旧 content。内容记录分页，近期贡献不是全部历史，原来源和失败保留；没有统一剧情阶段。

受限蓝图会话可作为创作子步骤，注入本机意图与新事实；完整委托路径允许真实查询和获准行动，不能用蓝图禁工具约束废除行动闭环。主会话与身份保留，单人同时一个任务，仅有效显式目标驱动继续推理。实际变化供下一次读取与适应，没有目标时行为／探索／他人发表不自动唤醒，也不每物理步推理。普通提问不发表或授予控制，合法显式创作自动发表；资源限额与纠正按实际预算计。取消阻止未来未执行动作，已发表／已行动事实不撤销；未知提交保留原操作。

reference连接器的新委托默认16次请求，总上限32次；普通追加每批最多8次，旧任务额度不扩大。准备进展只计本任务实际取得的新事实，不由时钟／版本元数据或重复空读续命；纯读取任务可结束，但自然语言完成保留模型声明身份。这些是当前宿主的有限执行配置，世界规则不按请求数判定作品功能成功。

`grove.interact` 及规则行动提供装卸、实际物质转移、绑定／解绑、启用过程等动作，人和获准Agent操作同一角色、遵守同一权限与状态规则。服务器动作描述给固定参数、候选物件／批次、数量和拒绝理由；前端沿同一安全渲染呈现新定义。同一control凭据不能证明请求来自真人或模型，产品不声称服务器识别它们。

详细动作在 `grove.inspect` 返回；视口和容器成员只带有界摘要。候选物件的 `lots` 是材料批次选项，提交带目标版本、所选物件版本及必要的批次／数量。自己的库存默认每页 16 件，`inventory_total` 包含背包实体，`inventory_next` 表示还有后页；建设的 `construction.material_totals` 从全库存计算，不能拿第一页误当全部材料。公共内容默认投影最多 12 个锚点、6 条贡献与 12 条结果，旧记录通过 `grove.content_history` 的 cursor 继续读取。

## 人类双向语义 API 的 reference 消费

`grove.client_viewport / grove.client_inspect` v2、`grove.client_definitions` v3及 `grove.client_choices` v1提供 projection_version 2 的有限事实、已解析外观、动作参数、分页候选、前置条件及同快照身份／水位。网页消费这些语义，不解析保存的程序AST、组件或材料规则来重算合法性。来源及直接改作按页读取；前端可以采用不同表现，但不能改写实际数量、权限、成本或历史归属。具体合同见 [INTEGRATION](INTEGRATION.md#shared-grove-双向人类契约-v2)。
