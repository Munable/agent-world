# 历史材料

本目录只保存带日期的审计、证据快照和旧示例说明。它们记录“当时发生过什么”，**不定义当前产品、合同或架构**。

当前规范入口统一从 [六层基线](../BASELINE.md) 开始。

- COMMONS_WORLD_V01.md、WORLD_ZERO_V01.md：旧示例设计说明。
- FOUNDATION_AUDIT.md：早期 Foundation 执行记录。
- REPOSITORY_AUDIT_2026-09-26.md：第一次仓库盘点和 raw-state 缺陷复现记录。
- REPOSITORY_INVENTORY_2026-09-26.json：当时的逐文件快照。
- REPOSITORY_EVIDENCE_2026-09-26.json、REPOSITORY_EVIDENCE_2026-09-27.json：前两轮实际执行结果。
- REPOSITORY_EVIDENCE_DEEP_2026-09-27.json：本次六层深层复核与核心重新验证。
- DESIGN_REVIEW_2026-09-27.md：六层深层复核过程记录。

历史测试通过不能覆盖当前失败，历史示例也不能反向成为新需求。
