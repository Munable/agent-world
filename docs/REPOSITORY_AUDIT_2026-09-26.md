## 修复与约束的准确范围

恢复提交前 managed-state 重校验及 SDK 写入记录；兼容合法 raw SQL，不用删除兼容接口来掩盖问题。
修复额外适配当前 `authorization_state`，授权回调按只读方式执行；SDK 正常的自撤销不被事后重新授权而错误拒绝。
状态变化检查有数量上限；版本必须逐次增加。初始化／迁移仍验证最终存活状态，不强迫迁移中间形状满足最终 schema。
新增迁移中间态、授权查询、SDK 自撤销、版本跳跃、未声明键、初始化回滚及 timer raw 写入失败测试。
这不是任意 SQL 与 SDK 全面等价的证明，不覆盖特权管理连接、恶意 Python、外部副作用或未声明 WorldDefinition 的旧注册路径。

新增 `tests/test_architecture_boundaries.py` 随现有 unittest／CI 入口运行：检查内核／SDK 不反向导入适配层和具体世界；检查重点回归方法仍在；并验证检查器能识别嵌套和相对导入。
这是轻量静态提示，不分析动态导入、不证明实现语义，也不能代替审阅测试是否被弱化。没有建立额外的架构服务、审批引擎或强制目录树。
