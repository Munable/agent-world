# 横轴：人类交互与表现

人类通过独立的双向语义 API 参与 Agent 原生世界。本文约束这份接口怎样表达获准事实与选择，以及 renderer 怎样翻译呈现、收集输入并忠实显示后果。表现不是新的语义层，也不拥有独立业务权威。

OpenCode 与二维网页是当前 reference adapter。当前实现、接口 shape 与限制见 [IMPLEMENTATION](IMPLEMENTATION.md) 和 [INTEGRATION](INTEGRATION.md)，实际体验与失败见 [当前研发记录](SHARED_GROVE.md#当前研发记录)。可替换责任已定义，不代表其他前端、设备、宿主或模型已经验证。

## 人类 API 与 renderer

人类 API 从同一世界查询、授权与动作定义生成版本化合同，提供获准事实、可知性、时间范围、当前选择、候选、参数护栏、拒绝原因与结构化意图。输入经同一世界身份、资格、版本和提交路径处理，与 Agent 行动共享 Operation／Receipt。

renderer 可以采用地图、文字、语音、卡片或其他呈现，改变布局、字体、相机、动画与输入方式。它负责把人类 API 翻译给人，把选择和输入交回世界；不能解释存储实体、能力名、规则键或作者程序来判断“能不能做”。

Agent 的事实、规则与创作接口按 Agent 需要提供。人类投影帮助人理解世界，不能替代 Agent 的原行动证据，也不能把宿主私人记忆或推理搬到世界服务。

服务器返回的自然语言、资源引用与表现参数均是数据，不因进入界面就成为 HTML、代码或控制指令。未知字段和不支持的合同版本明确报告，不能自行补默认规则。

## 当前事实、选择与后果

前端按获准事实表达对象、材料批次、槽位、数量、容纳关系、位置、载荷、过程、规则字段及合同状态。展示粒度可以不同，但每个事实的身份、单位、来源、可知性和时间范围须保留。隐藏或缺失字段是未知，不是零，也不复用上一帧的值。

动作由世界提供固定参数、实际候选、数量与模式范围。当前可用只表示读取时的资格，提交时仍由原动作验证当前条件；导航观察也不承诺每一步移动必定合法。输入辅助不能自行预留库存、替换来源或创建虚拟材料。

选择对象时读取当前条件，发送后防止重复提交。取消或断网保留原 Operation，先查原 Receipt；动画结束、按钮状态和模型说明都不表示提交成立。拒绝须表达真实原因，不能用漂亮过渡掩盖材料不足、空间不足或授权失败。

人的已编辑表单保留原来源、参数与观察版本。刷新只提示变化，不能悄悄改换数量、来源或目标；采用新护栏需要明确重新选择。超预算概要沿正式读取关系展开，不能从名称猜回候选。

## 历史与现场分开

发表时说明、固定定义、历史输出、原回执和当前物件状态分别展示。对象移走、装满、破损或不可读后，原说明不继续承诺现在仍成立；新详情也不能倒填为原提交读回。

定义发表与实际形成实例分开，改作是新的不可变版本；旧实例不因出现新版本而变形。蓝图浏览使用世界给出的类型、安装资格、真实来源及意图，前端可按正式数量约束帮助合计用户选中的真实批次，不能通过解释作者程序猜测成型资格。

事件发生、记录器启用后在获准范围内记录，以及某主体实际读取，是独立事实。页面不补造过去记录或私人观察。合同分别显示发布、实际接受、真实交付、条件结果与完成／失败／释放，沉默不显示为接受。

公共目录只表达当前公开作品的有限事实与位置，不表示远处地形、作者在线或远程行动资格。目录建立中、尚有后页、无匹配与完整空集分别表达；空页不证明世界不存在某作品。到场后读取当前条件，前端不能自动传送或据目录远程操作。

历史表现与当前现场明确区分。恢复旧历史不把已发生的奖励、伤害或动作再次播放成新的世界效果。

## 私人控制与宿主状态

人决定目的、亲自行动或明确委托。普通提问不自动授予行动控制，人的操作不等待模型完成。界面显示真实授权目标、行动范围、资源边界、执行状态和收回入口；用户无需逐项审批规则已经允许的行动或内容。

计划、正在调用、已提交行动、实际读回和模型声明分别显示。Agent 的叙述须能对应原任务、请求及会话；取消后的回复保留为历史，不变成当前结果。剩余额度依据原任务累计用量，接段或恢复不重置预算。

离开世界、停止推理、收回行动控制和撤销凭据分别显示。收回后取消未来未执行行动，已提交后果不回滚，原未知结果仍沿原回执恢复。无法确认宿主空闲、撤销结果或本机证据已保存时，显示准确未决状态。

宿主安装、适配可用、身份可用、世界权限可用、模型实际回应与实际世界读取是不同事实。健康检查、配置下载或本地标签不能冒充完成回应或读取；某个 reference adapter 的入场检查不成为世界通用资格。

私人意图、未发送表单、草稿、偏好与对话由用户侧保留，不自动发表。宿主状态接口只表达连接、请求、授权与原提交关系；当前对象详情从世界人类 API 单独读取，不通过宿主镜像补造现场或证据。

## Shared Grove 的参考呈现

二维 reference renderer 按获准视口显示地形、实体、人物、材料及活动过程，选择后展示世界返回的动作。它提供一种具体翻译方式，地图、键盘与鼠标不是通用世界前提。

物件与人物的显示标记保持各自稳定身份。同格多件物品分别列出，附近文字避免互相覆盖；空间不足可截断文字，但保留选择入口与完整列表。不能把不同对象相加为一个数字，或把未知作者字段显示成零。

选中详情先表达名称、简洁当前事实与动作；材料、物理、规则条件、历史输出和发布说明可以按语义分区展开。原始身份与关系入口可继续查阅，无需把全部字段堆在首屏。历史范围明确标记，保存输出不冒充当前过程。

现有皮肤与共享默认表现可以并用，新对象需有 fallback。图形比例对应真实逻辑尺寸，换皮不改变能力、位置或规则；资产缺失时不展示成已上传。有限声明呈现可把获准字段绑定为静态形状、颜色、字样、姿态或标记，未映射保持未映射。字段名称本身不创造物理机制、动画或成功证据。

真实容量限制、原处释放、容器关闭及读取拒绝应忠实表达，不能由动画复制嵌套内容。普通公开物件、受保护背包与安全区沿世界可见性显示；署名不等于永久产权。

物理与世界期限按逻辑时间表达，停机暂停、重启接续；机会租约与连接超时是运维信息。运行天数、刷新次数或模型调用数不表示探索深度或目标完成。

## 表现信号

世界可随已提交行动生成开始、结束、发言或公开意图等表现信号。信号只描述已有逻辑事实，不是第二控制平面；播放完成不能触发隐式业务提交。

受众由世界规则与可见性决定，信号名称不扩大范围。公开意图须来自主体明确提交，不能由世界或前端推测私人思考。

表现队列可丢失、过期或被缓存驱逐，重要进行中业务仍从授权状态与视图恢复，不能依赖动画保留在内存。

## 恢复与乱序

人类 API 返回同一读取快照的水位。renderer 核对世界、主体、代码、合同版本和请求代次，拒绝旧水位或旧选择响应。逻辑时间、对象版本与 Receipt 提交顺序各有用途，不能代替读取水位。

重复表现信号去重；身份切换后旧异步操作不能继续发送或渲染到新身份。授权撤回后不凭受保护旧缓存获取新事实。原操作恢复成功后才清除对应错误，拒绝或失败仍保留真实反馈。

接口升级不受支持时阻止新动作，保留原未知 Operation 的恢复路径。刷新、清缓存和取消动画都不改变世界结果。

## 语义与验收

文案、动画、缓存、音效、模型总结和本地队列都不能创造世界未形成的事实。发送、投递、读取、回应、确认、执行和完成各对应真实世界语义；简化界面不能把它们合成误导状态。表现发现模型或合同难以理解时，反馈到所属层明确修改，不能在客户端自创规则。

客户端验收关注以下合同：

1. 重放或重复读取不制造第二次行动。
2. 乱序响应不回滚对当前世界的理解。
3. 权限撤回与身份切换不继续使用受保护缓存。
4. 表现丢失后仍能恢复业务和原未知操作。
5. 文案准确表达当前、历史、未知、拒绝与领域完成。
6. 人类输入与 Agent 行动进入相同资格和提交边界。

布局可读、操作成功、真实 Agent 可靠性、真人体验及其他 renderer 分别验证。美术、相机或领域动画不是通用内核门槛；局部屏幕结果不扩成全设备验收。证据规则见 [REFERENCE_GATE](REFERENCE_GATE.md)。
