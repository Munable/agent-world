# 横轴：交互与表现

复核：2026-10-07。本文约束客户端怎样 **忠实表达已经成立的世界事实**。0.24 是本地当前最佳已验证切片，材料接续、普通解释复验、恢复及实际 Chrome 交互已有证据，最终源码／安装包检查通过；真人乐趣、移动端验收与全部表现合同仍未验证。表现不是 L7，也不拥有独立业务权威。

## 当前官方参与路径

Shared Grove 的玩家通过二维地图、键盘移动、鼠标选择与行动菜单亲自游玩；每人必须接入自己的 OpenCode。网页连接本机专用会话，Agent 解释当前事实、回应用户，并因实际探索／公共变化贡献有界内容。玩家决定移动和物件操作，专用 Agent 会话不提供这些代玩工具；正常行动不等待模型完成。具体世界合同和唯一当前研发记录见 [SHARED_GROVE](SHARED_GROVE.md#当前研发记录)。

地图显示获准视口内的 chunk、实体、其他玩家位置、材料状态、活动过程和变化。鼠标选择后只展示服务器实际返回的行动；动画、天气效果和 Agent 叙述都要对应可读回的事实。原作者描述和发表快照标为“发表时的说明”，实时物件详情、当前容器内容和归属独立展示；旧快照、他人的动作和系统来源须可区分。

最新地面容量修复为燃烧公共容器保留未来释放空间，空间不足时点火原子拒绝、不扣工具；后续放下也不能占用该空间。界面应忠实显示拒绝与实际原处释放，不能由动画复制嵌套内容。两项回归、包含修复的最终 535 项与实际安装包检查已通过，具体证据见 [当前研发记录](SHARED_GROVE.md#当前研发记录)。

## 让玩家从现场做选择

页面直接呈现服务器投影：真实材料批次／槽位／数量、容纳和绑定关系、载荷与承载、完整度、当前燃烧批次和过程。动作由 `action_options` 描述固定参数、可选实体／批次、数量、模式与拒绝原因。新注册构造沿同一表单和地图比例呈现，不按名字写专属交互，也不运行模型生成的脚本。

人决定装载、卸下、绑定、解绑、下水和其他使用。选择对象时读当前版本与候选；动作进行中防重复，取消或网络中断保留原 Operation，先查原 Receipt，不把动画结束或模型描述当提交成立。材料投入按实际数量，不能强制恰好选择若干完整物件。

公共内容呈现当前地点／对象 anchors、不同作者的贡献、真实 outcome 与有界历史分页。发表时说明与当前事实分开；原对象移走、装满或破损后，不继续显示原说明承诺仍成立。普通地面物件公开，背包／出生安全区保护；署名不是永久产权。

私人意图可在本机保存，明确只影响自己的主持选择，不发表为世界事实。主持面板是解释／创作状态，不是人的行动队列和提案审批；人继续操作世界无需等模型。离开、停止推理、撤销凭据分别显示，已有世界事实和过程不因此撤回。

0.25 候选已实际打开两个独立玩家入口。A 将原干布装进 B 留下的袋子，B 合上、打开、拿进背包再公开；A 在权限拒绝后仍能读取现场和移动，原袋子及内容 ID 没有复制。公共子物件经刷新仍可持续查看，关闭时明确拒绝读取，重新公开后恢复当前事实；对象提交前的 403／404 与真正凭据失效的 401 另有实际函数回归覆盖。未发送草稿保留、清空及前进后退接续已实跑。当前桌面 1280×900 与窄屏 390×844 的截图、具体动作及恢复范围只在 [当前研发记录](SHARED_GROVE.md#当前研发记录) 和唯一外置索引接续；窄屏无横向溢出不等于全部移动端验收。这些局部路径已成立，但主持可靠指导、真人趣味性、跨机器和规模仍未通过，最佳版本仍为 0.24。

## 有限的个人 Agent 参与

首次实际入场后，个人 Agent 的自动参与默认上限为 4 个 OpenCode message 请求，失败与唯一纠正计入；界面同时显示是否开启、已用／剩余额度和“停止自动参与”。新区域探索或附近已提交的物件操作／建设才唤醒，无变化不推理，忙时合并；重复刷新、恢复旧历史、领取／发布内容和过程计时不能制造新唤醒。已用量与范围持久化，同钥重连不重置。停止取消当前专用推理，保留已发表内容与世界过程；额度耗尽、停止或断线须可辨认，玩家仍能亲手移动和操作。

自动参与根据当前有界公共事实贡献可操作内容，不要求玩家编写生成提示词或逐项审提案。显式创作放在高级入口；普通提问只解释，不被当成发布。生成实物消耗真实公共节点库存，初始水扣公共水源，雨用有限过程水量；这些内容仍受活动容量限制。已消耗的库存不会因容量释放而凭空返还。预算不足、材料不足、机会过期和不支持的动作分别解释，不能把等待模型显示成世界行动尚未成立。

连接界面区分 OpenCode 可用、专用会话完成回应、实际 MCP 世界读取、当前连接失败或额度耗尽。首次完成回应与实际 MCP 读取形成客户端入场门槛，不能用服务健康、下载配置或本地标签冒充。世界服务器仍按持钥身份与普通行动规则处理，不认证工具或模型本体。入场后失联应保留玩家控制和已提交事实，并准确显示陪伴状态。

旧 0.24 A／B 恢复原身份与同主会话，无新入场推理；原 Operation 移动核对无重复。第 12 次失实保留，第 13 次注入新现场后同模型复问正确，实际用授权 14 次中的 13 次，自动参与均关闭。冷启动仍偶发 45 秒超时，普通 recover 复用健康宿主成功。

旧 0.24 原生 Chrome 实际覆盖 390×844 的右／左／下移动、材料不足时禁用搭建、情境栏开合和抽屉中的正确解释。未发送草稿经 UI 设置后刷新同钥重进，草稿、位置 (9,1)、水 20／30 及点火 20 次保留。正常离开曾误显“已连接”，修复后实际复验“已离开 · 可接续”；前进／后退再进入也已发生，无新模型请求。正常桌面与窄屏截图见 [当前研发记录](SHARED_GROVE.md#当前研发记录)，窄屏只说明局部布局／交互；草稿仍是私人未发内容，不成为世界发表事实。

玩家的长期目的和下一步选择无需形成 Runtime 的统一目标树、完成百分比或逐项审核流程。Agent 围绕发现解释少量可行方向，用户亲自决定／行动；网页沿行动、沟通、发现、决定与后果的轮次帮助回顾路径和他人留下的变化。雨、干燥与养护 tick 不计作玩耍轮次，运行天数、日活与每日任务不充当验收。连接授权、离开页面、撤销凭据和停止推理仍是不同操作。

通用内核允许其他世界定义不同客户端职责，Shared Grove 的操作和 OpenCode 会话边界不成为全部世界的固定玩法。

## 语义边界

- 文案、动画、缓存、音效、模型总结和本地队列都不能创造服务器没有形成的业务事实。
- “已发送、已投递、已读、已回应、已确认、已执行、已完成”必须对应真实领域语义；为了界面简洁不能把不同状态合成一个会误导用户的标记。
- 客户端发现模型／合同难以理解时可以反馈到 L3/L4，但在上层正式修改前不能自己发明新业务含义。
- 服务器返回的自然语言、资源引用和表现参数都是数据，不应因为出现在表现层就自动变成 HTML、代码或控制指令。

## 表现信号

Runtime 可以随着一个已提交世界动作发出用于表现的信号，例如动作开始／结束、发言或公开意图。表现信号只描述已经由世界规则产生的逻辑事实，不是另一套控制平面。

表现信号的受众必须由世界规则或已有可见性决定；名字叫 speech、intent 或 action 不能自动扩大可见范围。公开意图也必须是主体明确提交的数据，而不是 Runtime 推测私人思考。

表现信号可以与产生它的世界提交原子记录，但动画播放完成不能触发第二次隐式业务提交。

## 恢复与乱序

表现队列可以丢失、过期或被缓存驱逐；重要的进行中业务必须能从授权 View／State 恢复，而不是依赖某段动画仍在内存。

客户端必须去重重复表现信号，并拒绝把旧异步响应覆盖到新世界快照上。身份切换后，旧身份发起的异步操作不能继续发送或渲染到新身份；原操作恢复成功后才清除旧错误，拒绝或失败仍保留真实反馈。刷新页面、清空缓存或取消动画都不能改变服务器业务结果。

历史表现记录与现场表现必须区分；恢复旧历史时不应把已经发生过的奖励、伤害或动作再次播放成新的世界效果。

## 客户端验收关注点

1. 重放／重复读取不会制造第二次业务动作。
2. 乱序更新不会回滚客户端对当前世界的理解。
3. 权限撤回后不继续使用受保护缓存获取新数据。
4. 表现丢失后仍能从权威状态恢复业务。
5. 确认、完成、失败等用词与 L4 世界语义一致，而不是从网络状态或文本内容猜测。

具体 Presentation 类型、timeline/View 绑定、channel/phase、客户端 helper 和当前限制见 [IMPLEMENTATION](IMPLEMENTATION.md)。美术、相机、寻路和领域动画本身不是 Runtime 通用验收门槛。

## EigenFlux 参考建议

接入界面／宿主状态应分别表达“已安装／适配存在、身份已建立、权限当前可用、持续运行已授权或不可用”，不能把安装成功显示成 Agent 已在线。错误提示优先呈现安全的下一步动作，例如重新授权、等待后重试、恢复 Receipt 或重置 Snapshot，而不是把所有失败压成一句“请求失败”。

Reference Application 的通知、会话和未决事项要忠实表达服务器事实：等待不等于拒绝，通知读过不等于接受，不保证投递的操作不能显示成对方已读。名称与文案帮助人理解事实，但不能制造认证、关系或完成状态。
