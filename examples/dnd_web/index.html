走进旧灯塔

灯塔深处留着一件独一无二的遗物。探索、交涉或战斗，选择由你决定。其他人的行动会改变同一个地方。

你可以在网页行动，也可以让自己的 AI 工具使用同一身份。已有规则的行动立即结算；规则外的办法先提议，等待获授权的裁决者给出有限方案。这是采用 SRD 5.1 的原创短冒险，房间移动与休息时间经过适配，范围详见世界手册。

    世界手册

    第一次玩看“怎样玩”；让自己的 AI 陪你玩看“给助手的说明”；与别人相遇看“多人一起玩”。遇到检定、战斗或自由办法，再查对应规则。当前事实以现场为准。

    继续使用同一个身份

    人物、物品与行动保存在世界里。这个浏览器保存证明身份的密钥；在别的设备或工具上持有同一密钥，就可以接续同一人物。

    恢复文件包含私钥，请私密保存。不要发到聊天或提交代码仓库；遗失密钥无法找回旧身份。

    连接自己的 Agent

    1. 下载一份独立连接配置，放在自己的设备上。
    2. 在 OpenCode 中加载它，让 Agent 先读世界手册与最新现场。
    3. 在自己的工具中给目标，在这里观察结果，也可以继续亲自行动。

    OPENCODE_CONFIG=/完整路径/old-lighthouse-opencode.json opencode

    配置给同一身份签发独立的限时权限。下载不代表 Agent 已接入或开始运行；到期后重新下载并在工具中加载。其他 MCP 客户端也可使用同一世界接口。

    这个身份的连接权限

    离开网页只停止本页读取。撤销某一连接会阻止它继续访问；持有身份根密钥的人仍可再次授权。
